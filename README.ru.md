# GitHub Legacy

Нативный клиент GitHub для **iOS 6 – iOS 10**, сделанный для
джейлбрейкнутых 32‑битных устройств, которые официальное приложение
GitHub давно перестало поддерживать. Написан на чистом Objective‑C (без
проблем с ARC, без фреймворков новее iOS 6), так что старый iPhone или
iPad может листать репозитории, читать issues/PR и скачивать релизы без
Safari.

> Собирается через [Theos](https://theos.dev/) под `armv7`, минимум
> `iPhoneOS 6.0`. Требуется джейлбрейк.

## Возможности

- Вкладки **Обзор / Поиск / Избранное / Профиль** — в том же виде, что и
  оригинальное приложение GitHub.
- **Экран репозитория** — владелец, релизы, коммиты, issues, pull
  request'ы, звезда/снятие звезды, и полностью отрендеренный **README**
  (Markdown → нативный HTML, с кликабельными ссылками на коммиты/issue/
  PR/релизы, светлая/тёмная тема).
- **Issues и PR** — полноэкранные детали с тредом комментариев, списки с
  пагинацией.
- **Релизы** — просмотр changelog, скачивание assets с прогрессом.
- **Настройки** — светлая/тёмная тема и русский/английский язык,
  переключаются на лету; вход по Personal Access Token.

## Требования

- iOS 6.0 – 10.x, джейлбрейк
- Только `armv7` (32‑бит) — 64‑битные устройства не поддерживаются

## Установка

Возьмите `.deb` из [Releases](../../releases) и поставьте через `dpkg -i`
по SSH, либо откройте его в Filza/iFile и нажмите **Install**. Либо
соберите сами:

```bash
export THEOS=/opt/theos
cd githublegacy
make package FINALPACKAGE=1
```

Нужен iOS SDK ≥ 6.0 в `$THEOS/sdks/`; версию SDK в `TARGET =` в
`Makefile` подставьте под ту, что реально есть у вас.

## Вход в аккаунт

OAuth‑приложение не нужно — создайте **Tokens (classic)** на
github.com (**Settings → Developer settings → Personal access → tokens-Tokens (classic)**) и
вставьте его на экране **Войти** в приложении. Поиск и релизы работают и
без входа, в рамках анонимного рейт‑лимита GitHub.


## Контрибьюция

Issues и PR приветствуются, особенно баг‑репорты с реальных старых
устройств.
